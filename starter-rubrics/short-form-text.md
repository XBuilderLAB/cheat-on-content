# Starter Rubric：短文 / 微博 / X thread / 小红书图文 — v0 占位版

适用于短文、小红书图文文案、微博长文、X (Twitter) thread 等碎片化图文或纯文字内容创作者。短内容的消费时长通常在 10 秒到 1 分钟之间，第一眼注意力的争夺极其残酷，且非常依赖读者的情绪瞬时放大和转发站队。

---

## v0 综合分公式（短文版）

```
composite = (HK×1.5 + CO×1.0 + EM×1.5 + QL×1.2 + TS×1.5 + SR×1.3) / 8.0 × 2.0
```

每个维度 0-5 整数分。综合分范围 0-10。

---

## 6 个维度

### HK — Hook Potential（头图与前三行 Hook，权重 ×1.5）
*头图与文字前三行能否在飞速滑动的订阅流中，强行打断读者的手指，使其点击“展开全文”或点进大图？*

- **0** — 漫长的背景叙述（如“今天天气不错，我和大家分享一下我的经历...”）
- **3** — 提出了反直觉结论、强烈的矛盾冲突或悬念句（如“做了 5 年程序员，我才看清这个行业的三个致命谎言”）
- **5** — 视觉冲击与前三行文案形成强烈的认知不对称，读者不点开就无法释怀

### CO — Compression Ratio（信息压缩率/密度，权重 ×1.0）
*文章有没有多余的废话？是否用最精简的文字传递了最高密度的态度或信息？*

- **0** — 大篇幅的水字数、口水话，废话连篇
- **3** — 表达清晰，无明显长篇累赘，但可以通过精简语言将篇幅缩短 30%
- **5** — 字字珠玑，毫无冗余，每一个词都是精心打磨的有效信号（如 X thread 中单推的极简高密模式）

### EM — Emotional Amplitude（情感振幅，权重 ×1.5）
*短内容能否瞬间调动读者的情绪（如好奇、共鸣、愤怒、自嘲、温暖）？*

- **0** — 冰冷的客观事实叙述，无任何态度或情绪起伏
- **3** — 带有情绪色彩，但力度较温和，难以激起读者强烈的转发和站队欲望
- **5** — 情感张力极强，能精准放大某种痛点，引发读者瞬间的情绪投射

### QL — Quotable Snippet（金句传播力，权重 ×1.2）
*由于短文字数少，文章中是否有一两句适合做“金句标签”、能被读者直接存图、复制或转发的句子？*

- **0** — 通篇叙述性或大白话，无提炼总结性句子
- **3** — 结尾有一句不错的提炼，但稍显平庸
- **5** — 含有令人惊叹的妙语或洞察，独立传播力极强，读者转发时倾向于直接复制这句话

### TS — Topic Shareability（议题社交安全性，权重 ×1.5）
*读者转发或互动时，在 ta 的人设网络里，这个动作是否安全、是否能带来人设的加分？*

- **0** — 极具社交暴露风险（转发会被认为“ ta 怎么过得这么惨/ ta 怎么这么偏激”）
- **3** — 转发是中性的，多为表达一种兴趣或者保存收藏备用
- **5** — 转发本身就是一场低成本、高收益的人设秀（吐槽老板、集体共鸣、安全自嘲、价值观宣誓）

### SR — Social Resonance（实时热点/议题共振，权重 ×1.3）
*文章是否借了当下的实时热点情绪、模因（meme）或广泛讨论的阶层/职场议题的东风？*

- **0** — 完全脱离时代和实时背景的纯个人记录
- **3** — 挂钩了一个流行话题，但只是顺带提及，没切入核心痛点
- **5** — 恰到好处地将热点事件、社会潜意识与个人观点编织在一起，引爆了积压的集体情绪

## Bucket 预测（短文/微博参考边界）

由于短内容受平台算法推荐（如小红书发现流、新浪微博热门）影响极大，高爆发但稳定性弱，需根据不同平台账号的实际中位数 recalibrate。

| Bucket | 默认边界（微博/X新人起点）| 参考含义 |
|---|---|---|
| 底部 | <20 互动（转评赞） | 极少自然推荐，仅在私域被看见 |
| 基础盘 | 20-200 互动 | 进入了平台一级推荐池，引发小范围的赞同和讨论 |
| 命中 | 200-1000 互动 | 触发小爆，在特定圈层（如程序员圈、美妆圈）被快速转评 |
| 爆款 | 1000-5000 互动 | 大爆，进入平台全域发现流，带来大量关注和非粉互动 |
| 现象级 | >5000 互动 | 破圈狂欢，登上热门，引发大规模二次创作或挪用 |
