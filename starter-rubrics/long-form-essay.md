# Starter Rubric：长文公众号 / Newsletter / Substack — v0 占位版

适用于深度长文、Newsletter、微信公众号图文、Substack 等中长篇内容创作者。在这类形态中，读者的注意力时间更长，传播非常依赖于社交裂变（转发朋友圈、群聊或社交媒体分享）和读者的自我投射（“我是认同这种观点的人”）。

---

## v0 综合分公式（长文版）

```
composite = (TI×1.5 + LE×1.0 + QL×1.2 + UT×1.3 + ER×1.5 + SH×1.5 + ST×1.0) / 9.0 × 2.0
```

每个维度 0-5 整数分。综合分范围 0-10。

---

## 7 个维度

### TI — Title Clickability（标题吸引力，权重 ×1.5）
*标题与封面组合能否在海量订阅流中瞬间激发读者的“好奇心差距”或“必读感”？*

- **0** — 纯描述性流水账，毫无悬念（如“聊聊我最近的看书体会”）
- **3** — 表达了清晰的收益或反直觉观点（如“为什么越是聪明的人，越不倾向于制定详细计划”）
- **5** — 制造了无法抗拒的好奇心缺口或打破圈层常识，且未陷入标题党陷阱（如“低质量的执行力，正在成为你平庸的伪装”）

### LE — Logical Flow & Pacing（逻辑展开与节奏，权重 ×1.0）
*文章的起承转合是否顺畅？核心观点是否有层层递进的逻辑支撑？读者是否能一口气读完而不疲劳？*

- **0** — 结构混乱，逻辑跳跃，读起来像碎碎念
- **3** — 结构清晰（如标准总分总结构），分论点有说服力，但行文转换略显生硬
- **5** — 行文逻辑如手术刀般精准，节奏跌宕起伏，开头埋下的草蛇灰线在结尾有极佳的 payoff

### QL — Quotable Lines（金句传播力，权重 ×1.2）
*文章中是否含有 3 处以上可以被读者直接划线、截图、摘录在社交网络上的文字？*

- **0** — 通篇叙述性或大白话，无提炼总结性句子
- **3** — 有一两处写得不错，但属于常规道理（如“坚持就是胜利”）
- **5** — 含有多处独立可存活的金句，文字凝练、富有穿透力（离开文章上下文依然能独立击中读者）

### UT — Practical Utility（实用价值/知识密度，权重 ×1.3）
*文章是否给读者提供了可直接落地的方法论、有深度启发的新视角，或者足够硬核的信息差？*

- **0** — 纯抒情或废话，未提供任何实质性新知识
- **3** — 整理了已有的知识，或者提供了常见的信息，但有一定的整理和框架化价值
- **5** — 提供了极具独创性的认知框架，或者是一份极度硬核且无法在网上轻易找到的实践指南

### ER — Emotional Resonance（情感共鸣，权重 ×1.5）
*文章是否触及了读者深层的、具体的、不为人知（甚至不想主动承认）的情感？*

- **0** — 冰冷、严肃的学术性说理，没有温度
- **3** — 触及某种共识情感（如“打工人不易”），读者会点头认同，但情绪反应微弱
- **5** — 极其精准地戳中人性的软肋或普遍困境，读者在阅读时会产生“它在写我的生活，替我把压抑的感受说出来了”的震撼感

### SH — Shareability（社交货币/转发动力，权重 ×1.5）
*读者如果把这篇文章转发到朋友圈或群聊，是在帮 ta 进行怎样的自我标榜？（转发即表演）*

- **0** — 转发会带来社交尴尬或社交暴露风险（如暴露了自己的隐私缺陷）
- **3** — 转发是安全的，能表达自己的“关注领域”或“学习态度”（例如转发一篇技能干货）
- **5** — 提供了极佳的社交货币，转发能完美塑造读者的聪明、有同理心、有远见或品味独特的对外形象

### ST — Structural Novelty（话题/结构独创性，权重 ×1.0）
*选题和切入角度是否新颖？是老生常谈的翻版，还是极具破坏性的新视角？*

- **0** — 烂大街的陈旧话题（如“自律能带给你自由”）
- **3** — 话题常见，但切入角度有些许新意，或引入了新的对比
- **5** — 观察到了别人尚未定义的新趋势，或者将风马牛不相及的两个领域做出了精妙的交叉

## Bucket 预测（微信公众号/订阅号参考边界）

由于长文平台（如微信公众号）的分发更受“粉丝基数”和“朋友圈裂变”影响，中枢偏差较大。新创作者需按自身中位数进行 recalibration。

| Bucket | 默认边界（新人起点）| 参考含义 |
|---|---|---|
| 底部 | <100 阅读 | 仅有小圈子熟人打开 |
| 基础盘 | 100-800 阅读 | 被几位忠实读者转发，小幅自然流 |
| 命中 | 800-3000 阅读 | 触发了一定范围的私域裂变，在垂直群聊有小范围传播 |
| 爆款 | 3000-1w 阅读 | 破圈传播，阅读量达到日常中位数的 5x 以上 |
| 现象级 | >1w 阅读 | 达成多次跨层级裂变，多渠道自主转发 |
